# Public source versus restricted data

Organizer rules: https://huggingface.co/spaces/SageBio/rare-disease-real-kid-mva-hackathon-2026/blob/main/tabs/rules.py
Clarification: https://huggingface.co/spaces/SageBio/rare-disease-real-kid-mva-hackathon-2026/discussions/2

The clarification allows retained findings such as the final ranked candidate list,
mechanism report and code. It excludes genomic files, slices, indices, genotype-scale
tables and logs containing pasted genomic blocks. We take the narrower publication
option: code and generic documentation only in this repository. Final findings are
submitted through the organizers' UI. Do not redistribute reference providers' files
without their own applicable permissions. Download them independently instead.

Do not include secrets, HF tokens, signed URLs, patient data or private intermediates
in commits. Training-disabled settings are disclosed in the methods report; no claim
of contractual zero retention is made. Public release of code is required by the
organizers at close; this preparation step does not publish anything.
